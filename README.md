# 🎬 MovieFLIX – Dynamic Movie Catalog & Data Retrieval System

## 📌 Project Overview
MovieFLIX adalah platform katalog film dinamis yang dirancang untuk mensimulasikan pengalaman pengguna pada layanan streaming modern seperti Netflix. Proyek ini fokus pada efisiensi **data retrieval** (pengambilan data) dari dataset film skala besar dan penyajiannya melalui antarmuka yang responsif.

## 🚀 Key Features
*   **Dynamic Search Engine**: Memungkinkan pengguna mencari film secara real-time berdasarkan judul melalui filter data yang dioptimalkan.
*   **Advanced Pagination System**: Menangani navigasi ribuan data film dengan sistem halaman (next/previous) untuk menjaga performa loading website tetap ringan.
*   **Responsive Dark Interface**: Desain UI yang modern dan sinematik, dioptimalkan untuk berbagai ukuran layar.
*   **Structured Data Rendering**: Menampilkan detail film seperti rating popularitas, rata-rata voting, dan sinopsis secara dinamis dari database.

## 🛠️ Technical Implementation
1.  **Data Integration**: Mengelola ribuan entri data film (JSON/API-based) untuk ditampilkan secara asinkron.
2.  **DOM Manipulation**: Menggunakan JavaScript vanilla untuk memperbarui konten halaman secara dinamis tanpa perlu memuat ulang seluruh website.
3.  **Search Logic**: Mengimplementasikan algoritma filtering untuk mencocokkan input pengguna dengan katalog data yang tersedia.
4.  **Pagination Logic**: Mengatur pembatasan jumlah data per halaman untuk memastikan skalabilitas aplikasi saat dataset bertambah besar.
